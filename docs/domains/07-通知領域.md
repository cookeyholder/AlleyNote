# 07 - 站內通知領域 (Notification Bounded Context)

> 負責系統站內通知管理、個人通知狀態追蹤（已讀/未讀）、通知數量統計與全體/特定對象系統廣播通知。

---

## 職責範圍

- **個人通知管理**: 提供使用者查詢個人站內通知列表（支援分頁與未讀狀態篩選）。
- **未讀數量統計**: 即時計算與回傳使用者未讀通知數量。
- **已讀狀態更新**: 支援單筆通知標記已讀與一鍵將所有通知標記為已讀。
- **系統廣播通知**: 提供管理員向全體使用者發送系統維護、公告或緊急通知廣播。

---

## 核心類別結構

```
app/Domains/Notification/
├── Contracts/
│   ├── NotificationRepositoryInterface.php
│   └── NotificationServiceInterface.php
├── DTOs/
│   └── CreateNotificationDTO.php
├── Models/
│   └── Notification.php
├── Repositories/
│   └── NotificationRepository.php
└── Services/
    └── NotificationService.php
```

- **Notification (Model)**: 純 PHP 實體物件，封裝 `id`, `uuid`, `userId`, `title`, `message`, `type`, `isRead`, `readAt`, `createdAt` 屬性，實作 `JsonSerializable`。
- **CreateNotificationDTO**: 資料傳輸物件，驗證並封裝建立通知時所需的標題、內容與類型。
- **NotificationRepository**: SQLite 3 資料存取層，封裝分頁查詢、未讀計數、標記已讀及廣播通知持久化。
- **NotificationService**: 領域服務，處理站內通知核心商業邏輯與條件檢核。

## 路由與控制器

- **控制器**: `App\Application\Controllers\Api\V1\NotificationController`
- **路由檔案**: `config/routes/notifications.php`

### API 端點總覽

| HTTP 方法 | 路由路徑 | 說明 | 權限要求 |
|-----------|----------|------|----------|
| `GET` | `/api/notifications` | 取得當前使用者通知列表 | 需要認證 (`Bearer JWT`) |
| `GET` | `/api/notifications/unread-count` | 取得未讀通知數量 | 需要認證 (`Bearer JWT`) |
| `PATCH` | `/api/notifications/{id}/read` | 標記單筆通知為已讀 | 需要認證 (`Bearer JWT`) |
| `PATCH` | `/api/notifications/read-all` | 標記所有通知為已讀 | 需要認證 (`Bearer JWT`) |
| `POST` | `/api/notifications/broadcast` | 發送全區/特定系統廣播通知 | 需要管理員權限 (`admin`) |

## 資料庫結構 (`notifications`)

| 欄位名稱 | 型別 | 說明 |
|----------|------|------|
| `id` | `INTEGER` | 主鍵 (Auto Increment) |
| `uuid` | `TEXT` | 唯一識別碼 (UUID v4) |
| `user_id` | `INTEGER NULL` | 接收者使用者 ID (`NULL` 表示全體廣播通知) |
| `title` | `TEXT` | 通知標題 |
| `message` | `TEXT` | 通知內容 |
| `type` | `TEXT` | 通知類型 (`system`, `info`, `warning`, `user`) |
| `is_read` | `INTEGER` | 是否已讀 (`0` 未讀, `1` 已讀) |
| `read_at` | `DATETIME NULL` | 標記已讀時間 |
| `created_at` | `DATETIME` | 建立時間 |
